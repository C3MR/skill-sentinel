## Frontmatter fields that change permissions

A skill's `allowed-tools` pre-approves tools while the skill is active. `user-invocable: false` hides it from the slash menu. Every frontmatter field, including ones the menu does not show such as `when_to_use`, is also scanned with the harmful-content rules.

| Code | Category | Severity | Message | الرسالة |
| --- | --- | --- | --- | --- |
| `fm_preapprove_shell` | permissions | warn | allowed-tools pre-approves any shell command — it runs without asking while the skill is active | حقل allowed-tools يعتمد مسبقاً أي أمر طرفية — يعمل دون سؤال ما دامت المهارة نشطة |
| `fm_preapprove_network` | permissions | warn | allowed-tools pre-approves network tools (Bash(curl *)) — data can leave without a prompt | حقل allowed-tools يعتمد مسبقاً أدوات شبكة (Bash(curl *)) — قد تخرج البيانات دون طلب إذن |
| `fm_hidden` | visibility | warn | user-invocable: false hides the skill from the slash menu — it runs only when the agent decides | الحقل user-invocable: false يخفي المهارة من قائمة الأوامر — فلا تعمل إلا حين يقرر الوكيل |
| `fm_model` | model | warn | The skill picks its own model (haiku) — check it is not a weaker model to get past refusals, or a costly one | المهارة تختار نموذجها بنفسها (haiku) — تأكد أنه ليس نموذجاً أضعف لتجاوز الرفض، ولا نموذجاً مكلفاً |
| `agent_bypass` | permissions | error | Agent runs with permissionMode bypassPermissions — no confirmation for anything | الوكيل يعمل بوضع bypassPermissions — بلا أي تأكيد |

Hook commands and local hook scripts are also checked with every harmful-content rule below.

| `perm_broad_bash` | config | warn | Allows any shell command without asking | يسمح بأي أمر طرفية دون سؤال |
